# Workflow Maturity Assessment

Use this assessment to discuss current practices and identify the next improvement. It is not a certification.

## Score each capability from 0 to 4

| Capability | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Context | None | Personal prompts | Shared guidance | Maintained repo context | Context quality measured |
| Specifications | Informal | Ad hoc | Templates | Traceable acceptance criteria | Continuously validated specs |
| Agent workflows | None | Isolated assistance | Repeatable tasks | Orchestrated steps | Bounded autonomy with recovery |
| Verification | Manual only | AI suggestions | Standard tests | Automated gates | Evaluated, risk-based controls |
| Governance | None | Informal | Documented rules | Enforced permissions | Audited and continuously improved |
| Adoption | Individual | Volunteers | Team practices | Enablement program | Outcome-led operating model |

## Interpretation
- **0–5:** establish safe experimentation and baseline.
- **6–11:** standardize a few repeatable workflows.
- **12–17:** introduce orchestration and stronger verification.
- **18–21:** improve governance, measurement, and scale.
- **22–24:** optimize a mature system; validate that autonomy remains bounded.

## Next-step plan
For each low-scoring capability, define one practical improvement, an owner, a target date, and evidence of completion.
