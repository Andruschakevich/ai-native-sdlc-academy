# Contributing

Thanks for helping improve the AI-Native SDLC Academy.

## Contribution principles

- Keep examples vendor-aware but avoid presenting vendor-specific behavior as universal.
- Prefer runnable, small examples over abstract claims.
- Explain prerequisites, expected output, failure modes, and safety implications.
- Use fictional data and services only.
- Never submit employer-confidential material, credentials, customer information, or proprietary code.

## Lesson structure

A lesson should include:

1. Why the topic matters
2. Learning objectives
3. Core concepts
4. Practical walkthrough
5. Hands-on exercise
6. Expected outcome
7. Further reading or related artifacts

## Quality checklist

- [ ] Links resolve within the repository.
- [ ] Commands and code snippets are syntactically valid.
- [ ] Destructive actions are clearly identified.
- [ ] Security and human approval boundaries are explicit.
- [ ] Claims are supported or clearly labeled as illustrative.
